ViewOnly

Consent-based, view-only screen sharing.
No remote input. Auto-expires after 2 minutes.

This is a testing / educational project. The host must explicitly approve both the browser's screen-share prompt and the share itself. The viewer can never click, type, or send any input — only video is transmitted. The connection is end-to-end encrypted (WebRTC DTLS-SRTP) and auto-ends after 2 minutes or when either side presses End.
